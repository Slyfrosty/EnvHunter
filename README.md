# EnvHunter

**A powerful tool to find and extract sensitive secrets from .env files.*

## 🚀 Features

- Automatically scan directories for .env files
- Extract sensitive keys, tokens, passwords
- Generate clean reports
- Lightweight and fast
  
- ## 📦 Example Output
.env found at /leaks/dump/.env

AWS_ACCESS_KEY_ID=AKIAxxxxxxxxxxxx DB_PASSWORD=mydbpass JWT_SECRET=supersecrettoken

Saved to report.txt

## 📌 Usage

python3 envhunter.py /path/to/scan
